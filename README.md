# neuropus
Apprendre le Machine Learning, des maths de base aux transformers, par la pratique : arbre de notions, code corrigé dans le navigateur et répétition espacée.

> 🚧 Projet en conception.

## Pourquoi

Les ressources pour apprendre le ML ne manquent pas. Le problème, c'est qu'elles se rangent dans deux camps :

- celles qui rendent l'apprentissage agréable mais restent à l'intuition, sans jamais t'apprendre à entraîner un modèle ;
- celles qui vont au fond des choses mais demandent une autonomie que la plupart des débutants n'ont pas.

Entre les deux, beaucoup abandonnent. Et le plus souvent, ce n'est pas le code qui les arrête, ce sont les maths : vecteurs, dérivées, probabilités.

neuropus veut combler ce vide : une progression continue et exigeante.
